title: Hello, world
description: Why this blog is built from a single Sitefile.
tags: [meta, sitefile]
---

This blog is a folder of Markdown files and three templates. A **Sitefile**
turns them into static HTML — no framework, no `node_modules`, no container.

Each post starts with a little frontmatter:

```yaml
title: Hello, world
tags: [meta, sitefile]
```

The file name gives the date and the URL: `2026-01-05-hello-world.md` becomes
`/posts/hello-world/`.
